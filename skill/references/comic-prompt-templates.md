# 漫画书页面 Prompt 详细模板

## 一、完整漫画书页面的视觉元素清单

一张完整的漫画书页面应该包含以下元素（每项都要在 prompt 里明确）：

```
1. 页面框架
   - 竖版 A4 比例（9:16 或 2:3）
   - 整页白色背景
   - 黑色粗外框（页面边框）

2. 章节标题栏（顶部）
   - 顶部黑色横幅/条带
   - 中间留出标题文字位置（空白）
   - 装饰元素（如云纹、神兽剪影、古典纹样）

3. 分镜网格（主体）
   - 4 格上下排列（或 2x2）
   - 每格黑色粗边框
   - 格间白色分隔线
   - 每格独立画面

4. 每格内部元素
   - 主画面（角色 + 场景）
   - 对白气泡位置（白色椭圆/云形，留空文字）
   - 旁白框位置（黄色/白色矩形，留空文字）
   - 视觉效果（速度线/放射线/集中线/音效位置）

5. 页脚
   - 底部小区域
   - 页码位置（留空）
   - 章节信息（留空）

6. 整体风格统一
   - 固定色调（如国风的青绿/朱砂/水墨）
   - 固定线条风格（细腻线稿/水墨/工笔）
   - 固定光影处理
```

## 二、详细 Prompt 模板（整页 4 格）

```
竖版漫画书页面，A4竖版比例，白色背景，黑色粗页面外框。

【顶部章节标题栏】
页面顶部有黑色横幅装饰条，中央留出空白标题位置（后期加文字），
横幅两端有国风云纹装饰。

【主体 4 格分镜，上下排列，每格黑色粗边框，格间白色分隔】

第1格（最大，占页面 1/3 高度）：
【镜头】仰视特写
【场景】黑暗混沌的虚空中
【主体】雪白双角狮形神兽（白泽）的金色眼眸正在睁开
【细节】
- 眼眸：金色虹膜，瞳孔中有星辰流转
- 眼周：新生雪白绒毛，如初雪
- 光影：黑暗中只有眼眸和绒毛边缘的微光
- 角色设定：白色狮身，头生两只优雅弯角，通体雪白长毛
【对白气泡】画面右上角留一个白色椭圆气泡（空白）
【旁白框】画面左下角留一个浅黄色矩形框（空白）
【视觉效果】眼眸周围有放射状光线（集中线）

第2格（中等，占页面 1/4 高度）：
【镜头】中景
【场景】虚空逐渐清晰
【主体】白泽蜷缩的身体，双角初生
【细节】
- 身体：雪白长毛，湿润如新生
- 双角：头顶两个白色小凸起，透出微光
- 光影：通体散发柔和白光
【旁白框】画面顶部留白色横条（空白）
【视觉效果】身体周围有光晕

第3格（中等，占页面 1/4 高度）：
【镜头】俯视远景
【场景】昆仑山顶，云海翻涌
【主体】白泽迈出第一步，爪踩雪峰
【细节】
- 爪印：在雪地留下金色光痕
- 背景：昆仑山脉连绵，云海壮阔
- 比例：白泽渺小如针，昆仑巨大
【旁白框】画面底部留浅黄矩形（空白）

第4格（最小，占页面 1/5 高度）：
【镜头】特写
【场景】溪边
【主体】白泽抬头张嘴说话
【细节】
- 嘴部：微张，舌头可见
- 眼睛：金色，看向镜头
- 水珠：嘴角滴落
【对白气泡】画面右侧留白色云形气泡（空白）

【底部页脚】
页面最底部留小区域，左侧空白页码位置，右侧空白章节信息位置。

【整体风格】
国风神话漫画，山海经幻想美术，细腻线稿，
柔和电影光影，青绿与朱砂色调点缀，
高质量漫画书印刷质感。

【禁止】
不要生成任何文字，不要中文，不要英文，不要乱码，
所有文字位置留空白，不要现代物品，
不要改变白泽的白色长毛与双角设定。
```

## 三、单格详细 Prompt 模板（推荐，质量更高）

每格单独生成，prompt 要包含完整的环境 + 角色细节：

```
漫画书单格分镜画面。

【画幅】4:5 竖版单格，黑色粗边框包围

【镜头】仰视特写

【场景细节】
- 环境：混沌虚空，深邃黑暗
- 氛围：神秘、神圣、初生
- 空间感：无垠的黑暗中，主体是唯一光源

【主体：白泽（固定设定）】
- 物种：狮形神兽
- 毛色：通体雪白长毛，有银白与淡金边缘光
- 双角：头顶两只优雅弯角，白色，微泛金光
- 眼眸：金色虹膜，瞳孔中有星辰流转
- 本格状态：初生，眼眸刚刚睁开

【画面构图】
- 主体位置：画面中央偏上
- 视角：从下往上看（仰视），强调眼眸的神圣感
- 景深：眼眸清晰，周围绒毛柔和虚化

【光影设计】
- 主光源：眼眸本身散发金色光芒
- 环境光：极暗，只有眼眸和绒毛边缘有微光
- 对比：强烈明暗对比，黑暗 vs 金色

【留白元素（后期加文字）】
- 画面右上角：白色椭圆对白气泡（留空）
- 画面左下角：浅黄色旁白框（留空）

【视觉效果】
- 眼眸周围有放射状集中线
- 绒毛尖端有星光点缀

【风格】
国风神话漫画，山海经幻想美术，细腻线稿，
柔和电影光影，漫画书印刷质感。

【禁止】
不要生成任何文字，不要中文，不要英文，不要乱码，
不要现代物品，不要翅膀，不要变成普通狮子。
```

## 四、章节标题页 Prompt 模板

漫画书每章开头要有标题页：

```
漫画书章节标题页，竖版 A4 比例，白色背景。

【顶部】
大面积留白，天空感，几缕淡淡的云纹。

【中央】
黑色粗框矩形区域，中央留出大字标题位置（空白，后期加"第壹章"）。
框两侧有国风装饰：左侧白泽剪影，右侧昆仑山剪影。

【下方】
副标题位置（空白横条），后期加章节名"混沌初醒"。

【底部】
小字位置（空白），后期加"山海经·白泽传"。

【风格】
国风神话漫画，水墨留白，极简，神圣庄严。

【禁止】
不要生成任何文字，所有文字位置留空白。
```

## 五、完整章节结构（含标题页）

每章 5 页（1 页标题 + 4 格内容）：

```
第 1 章《混沌初醒》（5 页）
  页 0：章节标题页（白泽剪影 + 留白标题）
  页 1：第 1 格（仰视特写·金眼睁开）
  页 2：第 2 格（中景·双角初生）
  页 3：第 3 格（俯视远景·初踏昆仑）
  页 4：第 4 格（特写·张嘴说话）

第 2 章《初识人间》（5 页）
  页 0：章节标题页
  页 1-4：4 格内容

...共 6 章 × 5 页 = 30 页
```
