# 漫画书页面生成方法论

> 核心：**AI 负责画面，文字和排版后期手动加**。不要让图片模型生成中文（必乱码）。

## 一、核心原则

1. **AI 出图无文字**：prompt 里强制写"保留空白对白框/旁白框，不要生成任何文字，不要乱码"
2. **固定角色设定**：每张图都带固定角色描述（外形 + 禁止变化项）
3. **统一风格词**：所有页用同一组风格词（如"国风神话漫画，山海经幻想美术，细腻线稿"）
4. **反向限制**：明确禁止变化（如"不能变成普通狮子，不能长翅膀"）

## 二、两种生成方式

### 方式 A：整页一次生成（草稿/氛围页）
- 1 个 prompt 生成 1 张 4 格漫画页（横排或竖排）
- 优点：氛围连贯
- 缺点：4 格分辨率低，角色一致性差

### 方式 B：单格生成 + 后期拼接（推荐）
- 4 个 prompt 各生成 1 张独立图，再用 Canva/Figma/PS 拼接
- 优点：分辨率高、角色一致性强、可控
- 缺点：要手动拼接

## 三、Prompt 公式

```
【画幅/格式】+【风格词固定】+【主角固定设定】+
【本格内容：镜头+画面+动作+情绪】+
【反向限制】+【保留空白对白框，不要文字】
```

### 整页 4 格公式
```
竖版漫画书页面，四个横向分镜，上下排列，黑色粗边框，
【风格词】，细腻线稿，电影感光影，角色一致，

【主角固定设定】，

第1格：【画面、镜头、情绪】
第2格：【画面、镜头、情绪】
第3格：【画面、镜头、情绪】
第4格：【画面、镜头、情绪】

保留空白对白气泡和旁白框，不要生成任何文字，不要中文，不要乱码，
画面清晰，分镜节奏强，漫画书质感
```

### 单格公式
```
漫画分镜，第N格，【镜头景别】，【场景描述】，【角色动作情绪】，
【风格词】，黑色分镜边框，无文字
```

## 四、固定角色设定表（示例：白泽）

```
角色名：白泽
外形：雪白双角狮形神兽，白色狮身，头生两只优雅弯角，
      通体雪白长毛，金色眼眸，身形威严神圣，长尾如云，
      毛发有银白与淡金边缘光
性格：睿智、温柔、孤高、守护众生
能力：通万物之情，知天下鬼神之事
视觉关键词：白毛、双角、金眼、银光、神圣、昆仑、云海
禁止变化：不能变成普通狮子，不能变黑，不能长翅膀，
          不能变成人形，不能失去双角
```

## 五、章节结构（情绪推进，不只是事件列表）

```
章节名：
本章主题：
主角状态：
本章冲突：
关键转折：
结尾钩子：
本章页数：
```

每章 4-8 页（短篇），每页 3-5 格，短视频漫画固定 4 格。

## 六、4 格叙事节奏

| 格 | 功能 | 内容 |
|----|------|------|
| 第1格 | 提出目标 | 主角发现问题/做决定 |
| 第2格 | 解释/回应 | 角色给建议/世界观信息 |
| 第3格 | 翻书/揭示 | 章节/任务/线索/危机 |
| 第4格 | 强化主题 | 进入重点，留金句/钩子 |

## 七、对白规则

- 每气泡 **8-18 字**
- 对白直接，旁白诗意
- 中文**后期加**（PS/Canva/Figma），不要让 AI 生成

示例：
```
白泽：山河有灵，众生有命。
小麒麟：那我也能守护他们吗？
白泽：能。只要你先学会倾听。
旁白：那一夜，火光照亮了新的传承。
```

## 八、完整 Workflow

1. **角色设定表**：固定外形/性格/禁止变化
2. **章节大纲**：每章一个主题
3. **每章拆页**：4-8 页
4. **每页 4 格分镜**：写画面+对白+旁白
5. **生成图**：单格出图（带固定角色设定+风格词）
6. **后期排版**：黑框/气泡/旁白框/速度线/页码/章节标题
7. **统一风格**：所有页重复同一组风格词

## 九、画幅建议

```
单格横向：16:9
单格竖向：4:5
整页漫画：9:16 或 A4 竖版
```

## 十、推荐风格词组合（国风神话）

固定词：
```
国风神话漫画，山海经幻想美术，细腻线稿，
柔和电影光影，高质量漫画书页面，
黑色分镜边框，留白对白框，无文字
```

反向限制（按需）：
```
不要现代物品，不要文字乱码，不要多余角色，
不要变成普通狮子，不要翅膀，
不要改变白色长毛与双角设定，不要血腥恐怖
```

## 十一、对应到 xbrowser storyboard 命令

现有 `chatgpt storyboard` 跑漫画的两种用法：

### 用法 1：每镜 = 每格（单格出图）
```bash
# 一页 4 格 = 4 个 shot
xbrowser chatgpt storyboard \
  --shots "漫画分镜第1格,[场景],画幅4:5,黑框,无文字|漫画分镜第2格,...|第3格|第4格" \
  --progress ./page01.json --cdp 9221
```
输出 4 张独立图，后期拼接 + 加字。

### 用法 2：每镜 = 每页（整页 4 格）
```bash
# 一次生成整页（4 格合一）
xbrowser chatgpt storyboard \
  --shots "竖版漫画书页面4个分镜,第1格...,第2格...,第3格...,第4格...,无文字|下一页..." \
  --progress ./comic.json --cdp 9221
```
每镜 1 张整页图，不用拼接，但分辨率低。

## 十二、注意事项

- **AI 出中文必乱码**：prompt 里写"不要文字/不要中文"
- **角色漂移**：每张图都重复完整角色设定
- **画风漂移**：所有图用同一组风格词
- **分辨率**：整页 4 格质量 < 4 张单格拼接
- **后期工具**：Canva/Figma/PS/Procreate/Clip Studio
