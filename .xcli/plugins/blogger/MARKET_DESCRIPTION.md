# Blogger

> Blogger.com SEO 外链 - Google 免费博客平台 (DA 89, dofollow)

## 命令

- `login` — 登录 Blogger（Google 账号）
- `create-blog` — 创建新的 Blogger 博客
- `publish` — 在 Blogger 发布文章（dofollow 外链）
- `update-profile` — 更新 Blogger 个人资料（添加外链）

## 使用

```bash
xbrowser --cdp 9221 blogger <command> [options]
```

### 登录要求

本插件需要登录才能使用。请先在 Chrome 中登录Blogger，然后通过 `--cdp` 连接。
