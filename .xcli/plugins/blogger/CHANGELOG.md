# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [3.0.0] - 2026-06-10

### Added
- `login` — 登录 Blogger（Google 账号）
- `create-blog` — 创建新的 Blogger 博客
- `publish` — 在 Blogger 发布文章（dofollow 外链）
- `update-profile` — 更新 Blogger 个人资料（添加外链）
