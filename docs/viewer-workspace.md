# Viewer 浏览工作区

以 ChatGPT 桌面内置浏览器的标签页和地址栏为功能参照。打开命令返回的本地链接即可进入工作区：

```bash
xbrowser --session demo goto https://example.com
xbrowser session handoff demo
```

- 顶栏显示当前会话的网页标签页。地址栏接受完整的 `http`、`https` 网址和 `about:blank`，旁边可以前进、后退、刷新。
- 任务运行到 `handoff` 时，Viewer 顶栏显示等待状态，底栏出现「继续任务」。操作完原页面后点击该按钮，命令链会从暂停处继续。Chromium 在整个过程中保持无头运行。
- 自启动会话允许管理自己的标签页。外部附加会话的地址栏和标签页控件为只读，原有画面接管操作仍然可用。

## 手机和平板

Viewer 有触控模式。手机默认用触控板控制远端鼠标，平板默认直接点按画面。页面仍由运行 xbrowser 的机器渲染。

命令输出的 `localhost` 链接用于运行 xbrowser 的机器。标签页、地址栏和浏览历史控件仅在本机连接时启用。旧版接管通道缺少远程身份验证，请勿把 Viewer 端口暴露到公网或不受信任的网络。

## 架构决定

`浏览工作区 → Preview WebSocket → 已绑定的会话 → 活动页面`

工作区负责工具栏与标签页状态。画面、输入、设备模式、裁剪和文件交互沿用 Viewer 的原有通道。服务端将标签页操作限定在已绑定的会话中，CLI 和 Viewer 共用活动页面。连接中断时禁用导航控件，重连绑定后重新读取标签页状态。

工作区的标签页协议限本机环回连接。旧 Viewer 的流传输与接管通道沿用已有监听设置，应只在受信任网络使用。

这一结构复用已验证的画面与接管通道，可从终端链接直接打开。后续如果把同一工作区嵌入桌面或聊天面板，宿主仍可使用同一会话协议。
