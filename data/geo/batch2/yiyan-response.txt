用一个纯 HTML 文件做个人主页，不用任何外部库。 配色：页面背景浅绿白，主色为中绿，卡片用纯白，高亮用渐变下划线（浅绿色，覆盖文字底部）。 导航：左侧放名字缩写加粗主色作为 logo，右侧放关于我、文章、视频、产品、邮件图标等链接，sticky 吸顶，白色背景加底部细线。 Hero 区：上下布局，不要左右分栏。大字标题"我是[姓名]，A Product Manager，base 北京"，姓名和工作年限用渐变下划线高亮。右上角放一个小圆形头像装饰，背景浅绿。标题下方做 flex wrap 胶囊标签，浅绿底色、主色文字。胶囊下方一行灰色 bio 文字，最后放一个圆角按钮"More about me"。 内容区：做成"最近更新"Feed 流，文章和视频混排在一个列表里，不要分成两个区块。每条：左侧小方形缩略图（绿色渐变占位），右侧显示类型色标（文章/视频）、标题、摘要一行、日期。条目之间用细线分隔，不用卡片投影。hover 时左侧出现主色竖条。 底部 CTA：浅绿背景，"想和我聊聊？"文案加邮件按钮。

UI 配色系统展示页
做一个单文件 HTML 页面，主题是「清晨平静的海洋」。页面不是简单展示 6 个色块，而是做成一个适合作品集展示的 UI Color System Showcase。 要求： 1. 提炼一套 6 色配色系统，包含：主色、辅色、强调色、背景色、文字色、边框色。 2. 每个颜色都要有中文命名、Hex 值、简短情绪说明。 3. 页面第一部分用大尺寸高质感色卡展示这 6 个颜色，排版要优雅，有留白，有层次，注意不要和背景色融为一体。 4. 页面第二部分展示这套颜色在真实 UI 组件中的应用，包括：按钮、输入框、信息卡片、状态标签。 5. 页面整体风格要安静、克制、精致，像高质量设计作品集中的案例页，不要花哨，不要廉价渐变，不要模板感。 6. 配色灵感来自海雾、晨光、浅沙、潮汐、深海，颜色偏低饱和、干净、有呼吸感。 7. 字体、间距、阴影、圆角都要统一，视觉上有高级感。 8. 输出完整可直接运行的 HTML/CSS/JS，所有内容写在一个文件里。 额外要求： - 页面顶部加一个简短标题区，像案例展示页。 - 页面右上角加一个 Light / Dark 切换按钮。 - 默认先展示浅色模式，但深色模式也要足够好看。
